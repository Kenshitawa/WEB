# Mary Royal Primary and Junior School — WordPress Site Structure & Page Layouts

## Project Overview
A modern, mobile-first WordPress site designed in Elementor (free) using a lightweight custom theme. The structure emphasizes clarity, trust, and conversions (enrollments, inquiries, school visits) while ensuring strong performance, accessibility, and SEO foundations.

---

## Global Structure

### 1) Theme & Layout
- **Custom lightweight theme** with minimal PHP/CSS, optimized for Elementor.
- **Mobile-first** layout (base styles for mobile; progressive enhancements for tablet/desktop).
- **Typography**: Friendly, legible sans-serif pairing (e.g., Poppins + Inter).
- **Colors**:
  - Primary Blue: #1F4E79
  - Accent Green: #2A9D8F
  - Warm Gold: #F4B400
  - Neutral Light: #F8FAFC
  - Neutral Text: #1F2937
- **Visual style**: White background, rounded cards, soft shadows, clear spacing.

### 2) Header (Sticky)
- Left: Logo (Mary Royal Primary and Junior School)
- Right: Menu with dropdowns
  - Home
  - About Us
  - Curriculum
  - Classes (dropdown)
  - Admissions
  - Contact
  - News/Blog
- CTA button: **Enroll Now**

### 3) Announcement Bar (Customizer)
- Editable in Customizer (theme option)
- Example: “Admissions Open for 2025 — Book a Tour Today!”

### 4) Footer
- Address placeholder
- Quick links
- Social icons (Facebook, Instagram, YouTube)
- Footer CTA: WhatsApp and Call buttons

### 5) Floating Buttons
- Floating WhatsApp
- Floating click-to-call

## Performance & SEO Checklist
- Use optimized images (WebP where possible)
- Proper heading hierarchy (H1–H3)
- Short, descriptive permalinks
- Meta titles/descriptions for pages
- Schema-friendly structure (Organization, LocalBusiness)
- Lazy-load images

## Accessibility (WCAG Basics)

- Keyboard accessible menus
- Alt text for all images
- Clear focus states
